# Roadster Launch

A browser stunt game built with three.js: launch up a reverse-C ramp, come off it upside down, roll upright and jet-land, then hop the line-up.

Play: https://nathan6609.github.io/roadster-launch/

**Unofficial fan-made project.** Not affiliated with or endorsed by any car maker. All music and sound are synthesised in the browser; the pilot is an original character.
